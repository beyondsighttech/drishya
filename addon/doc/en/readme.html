Drishya

Image descriptions for NVDA using SmolVLM2 500M.

Install and download

  1. Install the add-on and restart NVDA.
  2. If the model is missing, choose Download or Later in the welcome prompt. The one-time download is about 662 MB and requires internet.
  3. Settings shows progress; Escape closes the dialog and cancels. You can retry later.
  4. After the model is ready, descriptions work offline. No GPU, separate Python, Ollama or external API key is required.

If you choose Later, open Settings from the description menu or NVDA's Tools menu. Requesting a description without the model also offers the download.

Describe

  1. Place focus or the navigator on visible content.
  2. Press NVDA+Shift+I, use arrows and Enter, and choose Entire screen, Current focus or Navigator object.
  3. In the result, Alt+C copies, Alt+D focuses the description, Alt+R retries the captured image, and Escape closes/cancels.

Last description reopens the recent result. Invisible objects must be brought into view. Capture happens before the menu appears.

Settings

Available in the menu and NVDA's Tools menu. Change detail (Alt+D), maximum image size (Alt+I), CPU threads (Alt+T), and automatic reading (Alt+R). Alt+M downloads/verifies the model; Alt+S saves; Escape closes/cancels.

Defaults: concise, 1024 pixels and four threads. Smaller inputs can be faster but lose small details. Model memory is released after five idle minutes or NVDA exit.

Screen Curtain

Where supported, Windows Graphics Capture captures while the curtain remains on. Drishya does not disable it automatically. If WGC is unavailable or fails, Drishya asks you to disable Screen Curtain and retry. Menu and Settings remain accessible.

Privacy and limits

Images are processed on this computer, not uploaded. Captures are discarded on close. The last description stays in memory until settings change, the session locks or NVDA exits. Copy writes text to the clipboard.

English descriptions; Windows x64 and NVDA 2026.1+. Capture backend availability depends on NVDA. Predictions can omit or invent details; quantization and resizing are not guaranteed lossless.

Troubleshooting

Missing/corrupt model: Download / verify model in Settings. Timeout: smaller image size. Clipboard busy: retry Copy. Shortcut conflict: change the binding in NVDA Input Gestures.
